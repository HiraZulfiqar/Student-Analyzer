# Student Analyzer

A beginner-friendly Machine Learning project that analyzes student data and predicts student marks.

## What This Project Does

* Loads student data using Pandas
* Performs basic data analysis
* Performs Exploratory Data Analysis (EDA)
* Creates visualizations
* Handles categorical features using One-Hot Encoding
* Scales numerical features
* Uses a Machine Learning Pipeline
* Predicts student marks using Linear Regression

## Technologies Used

* Python
* Pandas
* Seaborn
* Matplotlib
* Scikit-learn
